# 介面風格規範（草案）

> 2026-11-12 開會紀錄 #49 第 4 項：「介面風格、排版調整（簡潔清晰），AI 感太重」。
> 這份是調整方向與規則；第一步（拿掉裝飾 emoji 與內部編號）已完成，配色調整等其他 PR 合併後再一頁一頁套用。

## 為什麼看起來「AI 感」重

| 來源 | 例子 | 處理 |
|------|------|------|
| 標題前的裝飾 emoji | 📋 模組關卡進度、💡 分層提示、📊 AI 評分回饋 | ✅ 已拿掉 |
| 內部文件編號、技術用語 | 「待複核學生初評清單 (需求書 ASM-002)」、「AI 規準引擎串流評估」 | ✅ 已改成白話 |
| 深藍底配螢光色 | `#0f172a` 底、`#4ade80`／`#fbbf24`／`#7dd3fc` 的亮色字與半透明色塊 | ⏳ 改成淺色、低飽和（見下） |
| 每個區塊都有顏色 | 綠、黃、藍、紅、紫的標籤同時出現 | ⏳ 顏色只用來表示狀態 |
| 兩套風格並存 | 建立機器人、舊登入頁是淺色 Tailwind；其他頁是深色 inline style | ⏳ 統一成一套 |

## 方向

**淺色、中性、像學校的行政系統，而不是科技產品的展示頁。**

- 背景白色或極淺灰，文字深灰，一個主色
- 顏色只表達「狀態」：通過（綠）、需要注意（琥珀）、錯誤（紅）；其餘一律灰階
- 不用 emoji、漸層、陰影光暈；圖示只在有功能時使用（關閉 ✕、通過 ✓）
- 文字用老師與學生的話，不用內部術語（構面 → 評分項目、Rubric → 評分規準、Session → 不出現）
- 「AI」只出現在需要讓人知道「這是 AI 給的」的地方（AI 初評、AI 回饋），其餘說「系統」或直接省略

## 色彩（建議值）

| 用途 | 色碼 | 說明 |
|------|------|------|
| 頁面背景 | `#f7f7f5` | 偏暖的淺灰，比純白不刺眼 |
| 區塊背景 | `#ffffff` | 加 1px 邊框 `#e5e5e0` |
| 主要文字 | `#1f2328` | |
| 次要文字 | `#5f6368` | 說明、時間、計數 |
| 主色 | `#2f5d50` | 深綠灰：主要按鈕、目前所在的頁籤 |
| 通過 | `#1e7a46` 字／`#e8f3ec` 底 | |
| 需要注意 | `#9a5b00` 字／`#fdf3e1` 底 | 待複核、次數快用完 |
| 錯誤 | `#b3261e` 字／`#fbeaea` 底 | |

## 排版

- 字級只用三種：標題 18px、段落 14px、說明 12px；粗體只用在標題與數字
- 區塊之間 16px，區塊內 12px；圓角統一 8px
- 一個區塊只放一件事：例如練習頁的四欄，每欄只有一個標題
- 表格與清單靠左對齊，數字靠右

## 套用順序（等其他 PR 合併後）

1. 共用元件：`AdminNav`、`StudentModeTabs`、頁首（每頁都有，先改這兩個最有感）
2. 學生端：登入 → 系統選擇 → 我的課程 → 練習工作台
3. 教師端：監控總覽 → 複核 → 課程管理 → 模組管理 → 機器人
4. 建立機器人頁改成和其他頁同一套（目前是唯一的淺色 Tailwind 頁）

每改一頁都用桌機與手機寬度截圖對照，並請一位沒看過系統的人試用 3 分鐘，說說哪裡看不懂。
