## 3. 色彩

**來源**：主色取自老師提供的嫩芽圖示 `#2a9763`。嫩芽綠在奶油色卡片上的對比只有 3.5:1（不到無障礙標準 4.5:1），所以**按鈕與文字用加深的 `#1f6b47`**（白字 6.5:1），原色只用在圖示、進度條、大面積色塊。底色與灰色都偏暖（帶一點黃），模擬紙張與油墨。

| 用途 | 色碼 | 對比 | 說明 |
|---|---|---|---|
| 頁面背景 | `#f4efe4` | — | 米色紙張 |
| 卡片、區塊 | `#fbf8f1`，邊框 `#e4dccb` | — | 奶油色；不用陰影光暈 |
| 主要文字 | `#26221c` | 14.9:1（對卡片） | 墨色 |
| 次要文字 | `#6b6255` | 5.7:1（對卡片）、5.2:1（對頁面） | 說明、時間、計數 |
| 主色（按鈕、目前頁籤、連結） | `#1f6b47`，滑過 `#185a3b` | 白字 6.5:1、對卡片 6.1:1 | |
| 品牌綠（圖示、進度條、嫩芽） | `#2a9763` | 3.5:1 | 不放小字 |
| 主色淡底（選取、徽章） | `#e6efe4` | 字 `#1f6b47`：5.5:1 | |
| 螢光筆（AI 引用的原文） | `#f4d35e` | 墨色字 10.8:1 | 只用在劃線，不當底色 |
| 線條與停用 | `#cfc6b4` | — | 進度條底、鎖住的關卡、非重點圖表線 |

**語義色（全站只有這三組，paradigm-04）**：

| 意義 | 字 | 底 | 對比 | 用在 |
|---|---|---|---|---|
| 好：通過、已完成 | `#1f6b47` | `#e6efe4` | 5.5:1 | 通過、已發布、教師確認 |
| 注意：等待、快用完 | `#8a5a00` | `#f7ecd2` | 5.0:1 | 待複核、次數或預算快用完、AI 信心偏低 |
| 警告：錯誤、擋下 | `#a3361f` | `#f6e3dc` | 5.5:1 | 錯誤、個資被擋、預算用完 |

規則：
- 語義色以外的東西一律暖灰；**不用顏色單獨表達意思**，要同時有文字或圖示（✓、!、✕）
- 「好」跟主色同一個綠：通過就是在長大
- 圖表的分類色最多 3 個（主色、`#8a5a00`、`#cfc6b4`），非重點系列一律 `#cfc6b4`

## 4. 字與排版

- **標題用明體**：`Noto Serif TC`（頁面標題、區塊標題、大數字）；**內文與介面用黑體**：`Noto Sans TC`；英數跟著各自的字族
- 字級只用四種：頁面標題 26px、區塊標題 17px、內文 14px、說明 12px；粗體只給標題與數字
- **閱讀區**（AI 回饋、案例、教材、評分理由）：明體 15px、行高 1.9，像讀書（app-12）；其他介面文字黑體、行高 1.6
- 間距用 4 的倍數：區塊之間 16px、區塊內 12px；**圓角收小**：卡片 6px、按鈕與輸入框 8px、徽章全圓
- 清單「一行一件事」：左邊狀態、中間標題與一行說明、右邊徽章或數字；行與行之間一條 1px 線 `#e4dccb`
- 表格靠左、數字靠右（等寬數字）；表頭用次要文字色、不加底色
- 手機寬度（< 640px）一律單欄，按鈕至少 44px 高；長標題字級要能縮小，不能只剩一個字掉到下一行

## 5. 元件

| 元件 | 樣子 |
|---|---|
| 主要按鈕 | `#1f6b47` 底白字、8px 圓角；一個畫面只有一個主要按鈕 |
| 次要按鈕 | 卡片色底、`#e4dccb` 邊框、墨色字 |
| 危險按鈕 | 卡片色底、`#a3361f` 字；按下要確認 |
| 徽章 | 全圓、語義色的字＋底，例如「通過 85」「待複核」 |
| 進度條 | 底 `#cfc6b4` 的淡色、進度 `#2a9763`、高 8px、全圓；旁邊寫數字（4 / 7 關） |
| 關卡清單（學生端） | 已通過＝實心綠圈＋✓、目前＝綠框、鎖住＝暖灰圈；右邊徽章寫狀態，下方一行寫誰評的、幾分、日期 |
| 嫩芽成長（學生端） | 依「已通過的必修關卡 ÷ 必修關卡」換圖：0% 種子、1–49% 發芽、50–99% 兩片葉、100% 開花；旁邊一句話（「再通過 3 關就會開花」） |
| 螢光筆劃線（app-12） | AI 回饋裡引用學生原文的地方，下半截劃 `#f4d35e`（`linear-gradient` 做出手劃感） |
| 提示框 | 左邊 3px 色條＋淡底；資訊用暖灰、注意與警告用語義色 |
| 圖表（老師端，info-12） | 標題是一句結論（「本月 AI 費用有 6 成花在逐項評分」），副標寫單位與期間，線尾標名稱，底部寫資料來源 |

## 6. 文字語氣

- 用陳述與建議，不用命令和感嘆號：「這一關還差『具體行為』，補上就能通過」，不要「❌ 未達標！」
- 沒通過不用紅色；紅色只給真正的錯誤（個資、系統失敗）
- 不排名、不跟別人比較；進度只跟自己比
- 用老師與學生的話：構面 → 評分項目、Rubric → 評分規準、Session → 不出現
- 「AI」只出現在需要讓人知道「這是 AI 給的」的地方（AI 初評、AI 回饋、AI 整理）

## 7. 套用順序（#64）

1. 共用樣式：把上面的色碼、字族、字級收成一組共用設定（CSS 變數），各頁不再寫死顏色
2. 共用元件：`AdminNav`、`StudentModeTabs`、頁首、按鈕、徽章、提示框
3. 學生端：登入 → 系統選擇 → 我的課程（關卡清單＋嫩芽）→ 作答區與聊天室（閱讀區、螢光筆）
4. 教師端：課程管理 → 課程分頁（監控、複核、模組、教材、AI 用量、匯出）→ 建立機器人
5. 圖表：AI 用量、學習監控改成 info-12 的寫法

每改一頁都用桌機與手機寬度截圖對照，並請一位沒看過系統的人試用 3 分鐘，說說哪裡看不懂。
